# Open questions and roadmap
- Official SIWC eligibility, actual models, allowance, tool/streaming support and commercial rules; use BYOK if unavailable.
- Protocol native vs extension capabilities, SVG security, reactive expressions, streaming, state serialization and licenses.
- GenUI quality relative to ChatGPT, multi-turn correctness, latency and costs; no empirical results yet.
- Native hybrid/Tauri/Electron decision; WebKit compatibility, system integration and real hardware benchmarks.
- Graph UX: topic granularity, layout and navigation overhead, semantic zoom, actual user benefit.
- Context Core: long history budget, dedup, source deletion, snapshots, conflict display, token estimation and permissions.
- Artifact lifecycle: revision semantics, state migration, live references, export and portability.
- Commercial demand, target segment and willingness to pay; competitor hands-on evaluation.

Sequence: Goal 1 → review ADR → Goal 2 → evaluate → Context Core and Graph Lab (may proceed independently as designs) → walking skeleton → real personal-use validation. No date or performance claim. Current repository baseline is documentation only.
