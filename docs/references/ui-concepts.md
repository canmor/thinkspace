# UI concept reference (textual reconstruction)
Original in-chat interactive widgets are not exported as executable assets. These are behavioral references, not pixel-exact mockups or implemented UI.

## Workspace
Left sidebar workspaces; center graph canvas with topic cards and typed edges; right focus/inspector for selected chat, mixed response and composer. Overview shows titles, Explore shows summaries/preview, Focus full content. Auto layout with manual adjustment. Branch from selected message/text. Multi-select sources and start synthesis. No mandatory manual graph editing.

## Context composer
Input prompt with removable reference chips; select full/summary/selection and snapshot/latest where supported; inspect actual resolved sources, budget, exclusions and provenance. User can chat without opening inspector. Required overflow explicit.

## Decision matrix
Sliders for three weights; normalized scores, sorted bars, sample assumptions clearly marked. Instant deterministic local updates; explicit action sends selected state and data to AI. Promote independent artifact; restore state after reopen.

## Baggage explorer
Fare selector, Gold checkbox, weight slider, allowance and fee metrics, visual boundary bar; local updates follow B04 fixture. UI supports independent state snapshot and structured context export. No real-world policy claims.

## GenUI Lab
Left configuration (model, catalog, harness, task), two side-by-side protocol output panes, raw spec and validation trace, screenshots, token/time metrics, run history/replay. Goal 1 manual fixture selector, no inference. Goal 2 generation mode. Maintain equivalent visual components across protocols. No exact original screenshots or interactive state captured.
