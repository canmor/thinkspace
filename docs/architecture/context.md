# Context Engine v0.1 — proposed
History is a context source, not context itself. Distinguish authorization scope from selected content. Sources: conversations, messages, text selections, artifacts, documents. ContextReference includes source locator, range, snapshot/latest binding, original/summary/structured-state representation, required/optional priority. ContextSpecification declares references and policies; ContextEnvelope records actual selected content and provenance; provider adapter builds concrete request.

Compilation pipeline: resolve authorized locators and versions, enforce access before content retrieval/expansion, expand lineage, deduplicate by immutable message/content identity, select, budget, compose with role/source boundaries, record envelope. Check authorization for all expanded sources. Default branch inherits prefix snapshot; ordinary reference direct-only (no transitive expansion); provenance and semantic links do not propagate. Explicit live reference resolves at invocation time, fixed thereafter. Detect cycles. Merge is composition use case, preserve contradictions and source attribution.

Progressive control: implicit current history + inherited history + workspace constraints; optional explicit references; advanced inspector with selected/excluded sources, representation, versions, budget and reasons. Required context cannot be silently discarded; overflow requires explicit policy change. Reserve system/tools/output budget, account for provider tokenization. Prefer deterministic code for resolution, ordering, dedup, access and budget; optional model summarization with recorded summary. No semantic agent/RAG in MVP.

Generation record: exact submitted content or reconstructable versioned references, summaries, omissions, compiler/harness versions and model config; record provider-side context identifiers where available. Input reproducibility is not output reproducibility or proof of internal model reasoning. Treat referenced content as untrusted data, not privileged instructions. Enforce transfer permissions before remote calls.

Fitness tests: parent continuation leaves branch stable; merge dedups common ancestors; snapshot unaffected by artifact changes; missing source explicit; required overflow blocks; cycles terminate; provider switch preserves references; historical request manifest inspectable; UI cannot access other nodes without permission.
