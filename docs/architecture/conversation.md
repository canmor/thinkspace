# Conversation and workspace model — proposed
Workspace owns node and edge identities and integrity; separate canvas layout from semantic relationships. Node types: Conversation, Visualization, Interactive Artifact, Knowledge/Decision (future). Conversation nodes contain linear messages; immutable messages and versioned anchors preserve lineage without copying entire histories. Regeneration preserves prior versions. Branch from a message or text selection inherits historical prefix snapshot by default; parent continuation cannot change child history. Merge creates a new conversation referencing multiple sources, not a destructive merge or message concatenation.

Edge semantics: Branch (acyclic, default inheritance), Context Reference (explicit context inclusion, cycle-safe), Derived From (version-level DAG, provenance only), Semantic Relation (may cycle, no automatic context). Spatial grouping is layout metadata. Conversation, Context and Knowledge Graph are logical views, not necessarily independent stores. Knowledge extraction deferred.

UX: normal Chat and Graph views, automatically create and lay out branch nodes, allow manual adjustment, collapse/group and semantic zoom. Overview shows topics and links; Explore shows summaries and key artifacts; Focus shows full linear chat and interactive UI. Avoid mounting every full conversation simultaneously. Explicit references via @mention, drag, selection and inspector are equivalent domain operations.
