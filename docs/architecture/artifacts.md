# Artifact lifecycle — proposed
Stable artifact identity, content version, mutable interaction state, immutable snapshot, provenance, protocol/schema version and renderer requirements. Content revision changes version; slider changes do not. Promote inline block without losing source or state. Snapshot references fixed content/state; live references resolve latest at request time. Context Projection exports semantic data, rule/model definition where relevant, inputs, outputs and assumptions, not DOM or arbitrary code. Record source message/block, version and generation manifest. Restore independently from chat; branch versions without overwriting source. Future semantic diff and cross-node live binding deferred.
