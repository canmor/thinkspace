# GenUI Lab — Technical Spike Specification v0.1
Status: proposed. Objective: determine whether public models and reusable UI infrastructure can deliver autonomous, useful, correct, responsive GenUI comparable to native ChatGPT.

RQ: representation choice; expressiveness; deterministic local interactivity; visual quality; latency/token cost; independent artifact restoration; multi-turn evolution. Separate protocol feasibility (no LLM) from model quality. Negative results valid.

Stack: React, TypeScript, Vite, Apps SDK UI, Tailwind CSS, json-render, OpenUI Lang, SVG, chart library as needed, Playwright. Pin exact compatible versions and record licenses. Shared visual components and equivalent semantics; preserve protocol-specific differences. Modules: provider, harness, catalog/design system, protocol adapters, rendering/interaction, artifact model, evaluation, experiment runner. CLI and minimal side-by-side Web lab, raw outputs, run history, replay without model calls. No need for desktop shell.

20 initial primitives: Markdown, Heading, Text, Stack, Row, Grid, Divider; Card, Table, Metric, Badge, Callout; Chart, SVG, Diagram; Slider, Select, Checkbox, Input, Button. No benchmark-specific widgets. Safe SVG subset (path, rect, circle, text, group; allowlisted attributes), no scripts/external references/arbitrary events. Expressions: arithmetic, comparisons, conditions, derived state, aggregation, map/filter/sort, formatting, reactive bindings including SVG attributes. Record native vs documented extension vs custom vs unsupported. No arbitrary model-generated JS. Bound expression size/time/collections; validate before execution; deny filesystem/network/credentials/privileged APIs. Credentials outside browser state. Test hostile inputs. No private API reverse engineering.

Artifact: stable ID, protocol/version, spec, data, state, provenance, renderer requirements; independent restore and structured Context Projection. State updates separate from content versions. No cross-protocol portability required.

Goal 1: inspect docs/source/licenses, manually build equivalent architecture visualization, weighted matrix, baggage explorer specs, exercise interactions, save/reopen state, security negative tests. No LLM calls by application. Report support matrix and ADR. Goal 2 only after review: real official model access, versioned harness, mixed text/UI streaming, benchmark and native ChatGPT human comparisons, regression, replay. Preserve failures; no handcrafted substitution.

Evidence per run: config, dependencies, model/parameters, harness version, input, raw output, artifact, state before/after, screenshots, test results, validation errors, latency and usage if available, custom extensions and source references. Record failed runs. Redact secrets. Deliver working local Lab, reusable modules, tests, fixtures, reproduction commands, matrix, ADR and findings.

Non-goals: full chat client, graph/canvas, knowledge graph, memory, cloud sync, collaboration, production deployment, commercialization, native macOS renderer, custom model training or private API access. Suggested repo structure apps/genui-lab, packages/genui/{catalog,harness,runtime,adapters}, packages/model-provider, packages/design-system, packages/artifact-core, benchmarks/genui, experiments/genui, docs/architecture/adr. Do not scaffold unused future modules.
