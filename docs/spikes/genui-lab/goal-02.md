# Codex Goal 2 — Generation Quality

/goal

Only begin after human review of Goal 1 evidence and ADR. Use approved candidates and the repository baseline. Integrate real official model interface via provider-independent port (verify authorization; BYOK fallback). Build versioned harness with presentation/design/interaction/grounding policy, catalog, protocol instructions and examples. Reuse framework generation/parsing/validation. Generate mixed text and UI autonomously, stream semantic blocks, isolate failures. Run B01–B06, repeat three times where access/budget permits, record actual sample sizes and model configuration. Test multi-turn refinement with independent regression oracles. Preserve all raw outputs, validation errors, state, screenshots, timings, tokens and retries. Replay offline. Compare with manually collected native ChatGPT references; human assessment required for cognitive and visual claims. Equalize component semantics and model/config where feasible; distinguish baseline and optimization. No forced UI, task-specific widgets, hardcoded answers, test oracle leakage, hidden failures, private APIs, full workspace or unsupported claims of parity. Deliver evidence, classified failures, reusable packages and ADR with limitations. Optimize for trustworthy findings, not appearance.
