# Codex Goal 1 — Protocol Feasibility

/goal

Complete Goal 1 of GenUI Lab using this repository's README, AGENTS.md, architecture decision log, specification, benchmark and evaluation rubric. Obtain trustworthy reproducible evidence, not a polished demo. Inspect current official documentation/source/licenses for json-render, OpenUI Lang and Apps SDK UI; pin exact versions. Build minimal local React/TS/Vite Lab with shared visual primitives and separate adapters. Manually author equivalent B02–B04 specifications, with no application LLM calls. Test free safe SVG and reactive attributes, local deterministic calculations, conditions, aggregation/sorting, state export, independent persistence/restore and structured context projection. Use independent behavioral oracles and Playwright. Validate malicious/invalid specs, SVG, expressions and unauthorized host access. Preserve failures and distinguish native features, documented extensions and custom implementations. No domain-specific widgets, hardcoded expected outputs, custom DSL, full chat, canvas, desktop packaging or silent fallback. Do not weaken gates. Deliver reproducible commands, source, fixtures, automated test results, screenshots, raw specs/state, capability matrix, limitations, license notes and ADR recommending adoption/extension/hybrid/rejection. Negative findings count as completion. Do not start Goal 2 automatically; request human architecture review.
