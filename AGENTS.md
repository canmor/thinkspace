# Engineering handoff
Read README and linked baseline before implementation. Use Git as the SSoT. Accepted means explicitly agreed product direction; Proposed means design recommendation; Validate means evidence needed; Deferred means out of current scope. Do not infer approval from a proposal. Record changes in ADRs and keep failure evidence. Start Goal 1 only, with manually authored specs and no LLM invocation by the application. Do not start Goal 2 without review. Never commit secrets, personal chat transcripts or private data. Do not reverse engineer private ChatGPT APIs. Preserve independent test oracles, exact dependency versions, licenses and reproducible commands. Do not create empty future modules merely to match a proposed architecture. Report blockers and unsupported capabilities explicitly.
